# 연속 출석 이벤트 PRD

## 목적

사용자가 이벤트 기간에 매일 앱을 다시 방문하도록 짧고 명확한 연속 목표를 제공한다. 매일 코인을 지급하고 10일 연속 출석을 달성하면 방에 배치할 수 있는 한정 가구도 지급한다.

## 사용자 가치

- 오늘 출석 여부와 현재 연속 일수를 즉시 확인한다.
- 1~4일차 30코인, 5일차 50코인, 6~10일차 30코인이라는 보상표를 미리 확인한다.
- 10일차에 30코인과 보상 가구가 함께 지급된 결과를 확인한다.

## 운영 원칙

- 이벤트 기간, 일차별 코인 설정, 보상 가구는 운영자가 이벤트 생성 시 확정한다.
- 날짜와 하루 경계는 `Asia/Seoul` 기준이다.
- 코인과 보상 가구는 클라이언트 입력으로 선택하지 않고 서버의 이벤트 설정을 신뢰한다.
- 출석 기록·코인 적립·가구 지급·재화 원장 기록은 같은 트랜잭션으로 처리한다.
