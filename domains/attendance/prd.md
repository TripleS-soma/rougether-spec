# 출석 이벤트 PRD

## 기존 7일 STREAK 목적

이벤트 기간에 매일 앱을 방문하고, 7일 연속 출석을 달성하면 AI 가구 생성권 1회를 받는다. 받은 생성권으로 사진 속 가구를 루게더 가구로 만들어 내 방에 배치한다.

## 보상과 진입

- 기본 보상은 매일 30코인, 5일차는 총 50코인이다. 7일 완주 시 총 230코인과 AI 가구 생성권 1회를 받는다.
- 메인 나의 방의 반짝임 아이콘 `AI 가구 만들기`는 출석 완료 전에도 열 수 있다.
- 만들기 화면에서 생성권 잔액, 사진 선택, 생성 진행 상태와 완성 가구를 확인한다.
- 출석 완료 시트의 `내 가구 만들러 가기`도 같은 화면으로 이동한다.
- 출석 이벤트가 종료되어도 받은 생성권은 사용할 수 있다. 출석 생성권은 만료시키지 않는다.

## 운영 원칙

- 2026-11-04 사용자 결정: AI 가구 생성은 생성권 1회를 먼저 사용하고, 생성권이 없으면 100코인으로 이용한다. 실패하면 실제 사용한 수단으로 환급한다.
- 2026-09-07 사용자 결정: 새 이벤트 목표는 7일 연속이며, 정해진 가구 대신 생성권 1회를 지급한다.
- 사용자가 출석 시트의 `오늘 출석하기`를 눌러 출석한다. 여기에 더해 **그날(KST) 루틴 또는 할 일을 처음 완료하면 앱이 출석 시트를 띄우고 같은 출석 요청을 자동으로 보낸다**(2026-09-11 사용자 결정 — 9/7의 "자동 출석은 하지 않는다"를 대체).
  - 보상 알약이 사라진 뒤(약 2.6초) 연다. 도장·코인·완주 연출은 수동 출석과 같고, 새 출석(`newCheckIn=true`)일 때만 재생한다.
  - 진행 중 이벤트가 없거나 오늘 이미 출석했거나, 과거 날짜 완료·같은 날 취소 후 재완료·위젯 완료면 띄우지 않는다.
  - 자동 요청이 실패하면 시트의 버튼으로 다시 출석할 수 있다. 서버 계약은 그대로다(멱등 `POST /events/attendance/check-ins`).
- KST 하루 1회이며 하루 이상 빠지면 1일차로 다시 시작한다.
- 기존에 생성한 가구 보상 이벤트와 기록은 보존한다. 기간과 보상을 변경할 때 새 이벤트를 만들며, STREAK 내 활성 기간 중첩은 허용하지 않는다.
- 운영 시작일·종료일은 별도 운영 입력이다. 코드 배포만으로 이벤트가 활성화되지는 않는다.
- 생성권 지급과 출석·코인·원장은 같은 트랜잭션이다. 중복 요청은 보상을 추가 지급하지 않는다.

## 크리스마스 누적 30회 (2026-11-09 확정)

2026-11-09~12-25(KST 양 끝 포함)에 누적 30회 출석한다. 일반 출석 30코인, 5회마다(5/10/15/20/25/30) 그날 총 60코인으로 완주 합계 1,080코인이다. 빠진 날이 있어도 누적 횟수는 유지한다. 최종 특별 보상은 NONE이며 트리 완료 보상안은 폐기했다. 유니크 보상은 추후 결정하고 트리는 전용 뽑기에 포함한다.

선택된 5열 6행 선물 봉투 출석판을 사용한다. 제목은 `크리스마스`만 표시하고 감성 소제목이나 영어 문구를 덧붙이지 않는다. 출석 성공 후 연출을 마치고 닫으며 해당 KST 날짜에는 자동으로 다시 열지 않는다. 다음 날 서버 상태로 다시 판단한다. 접속 노출은 출석판이 완전히 닫힌 뒤 안내 팝업 순서이고 서로 겹치지 않는다.

`다시 보지 않기`는 안내 팝업에만 있으며 계정+안정적인 이벤트 코드로 서버에 영구 저장한다. 다음 날 출석판과 직접 이벤트 진입은 계속 가능하다. 11/26은 12/25까지 30회를 채울 수 있는 마지막 첫 참여일이며 이후에도 기간 안의 출석 코인은 받을 수 있다. 상세 API는 [api.md](api.md), 팝업과 공개 조건은 [크리스마스 기능 명세](../christmas/features.md)를 따른다.

기존 STREAK 이벤트, 출석 생성권 사용, 완료 후 자동 STREAK 출석 동작은 유지한다. 크리스마스 CUMULATIVE에는 이벤트 ID 지정 API를 사용한다. 공개 플래그와 운영 활성 상태는 최종 서버/새 iOS 빌드 검증 후 별도 절차로 켜며 문서나 migration 추가만으로 공개되지 않는다. 알림 발송은 이벤트 공개 절차에 포함하지 않는다.
