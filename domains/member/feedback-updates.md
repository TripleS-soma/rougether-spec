# 건의하기와 업데이트

2026-11-11 사용자 요청으로 내 정보의 주간회고 다시 보기 위에 `건의하기`, `업데이트` 순서로 추가한다.

## 사용자 흐름

- 건의하기: 제목 1~100자, 내용 1~2000자를 입력해 보낸다. 앞뒤 공백을 제외하고 빈 입력은 거부한다. 첨부 사진은 받지 않는다.
- 작성자는 자신이 보낸 건의를 최신순으로 볼 수 있다. 다른 회원에게 공개하지 않으며 작성자와 관리자만 조회한다.
- 전송 실패 시 초안을 보존한다. 전송 중 중복 탭을 차단하고, 계정이 바뀐 경우 이전 요청을 새 계정으로 재시도하지 않는다.
- 업데이트: 관리자가 게시한 제목, 본문, 게시일을 최신순으로 표시한다. 앱을 재배포하지 않고 서버 게시 내용을 반영한다.
- 기존 알림함의 번들 `새 소식`과는 별개 화면이다. 등록된 글이 없으면 빈 상태를 표시하며 임의의 공지를 만들지 않는다.

## 관리자 흐름

관리자 메뉴 `건의·업데이트`에서 두 목록을 확인한다. 건의에는 작성자 ID, 닉네임, 제목, 내용, 접수시각이 표시된다. 건의 삭제와 업데이트 추가·삭제를 지원한다. 삭제는 확인 후 영구 삭제한다. 업데이트 게시 성공 즉시 앱 API에 공개되며 별도 푸시를 보내지 않는다.

관리자 등록·삭제는 ADMIN/SUPER_ADMIN 세션과 CSRF 검증을 통과해야 한다. 사용자 API에는 업데이트 쓰기 경로가 없다. 입력 본문은 HTML로 실행하지 않고 텍스트로 표시한다.

## API

모든 사용자 API는 JWT 인증이 필요하다.

- `POST /api/v1/suggestions`: `{title, content}` → 201 `{id, title, content, createdAt}`
- `GET /api/v1/me/suggestions?cursor={id}`: 본인 건의 목록
- `GET /api/v1/updates?cursor={id}`: 게시된 업데이트 목록
- `GET /admin/suggestions?cursor={id}`: 관리자 건의 목록, 응답 항목에 `userId`, `nickname` 추가
- `DELETE /admin/suggestions/{id}`: 204, 본인 목록에서도 사라진다.
- `GET /admin/updates?cursor={id}`: 관리자 게시 목록
- `POST /admin/updates`: `{title, content}` → 201, 제목 1~100자, 본문 1~5000자
- `DELETE /admin/updates/{id}`: 204, 앱 목록에서도 사라진다.

목록 응답은 `{items: [...], nextCursor: number | null}`이다. ID 내림차순 20건씩 제공하고 더 없으면 `nextCursor=null`이다. 커서를 생략하면 처음부터, 주면 해당 ID 미만을 조회한다. 0 이하 커서는 400이다. 시각은 UTC ISO8601, 앱 표시일은 Asia/Seoul 기준이다. 관리자 삭제를 반복해도 204이다.

## 데이터와 보관

- `suggestions`: id, user_id, title(100), content(2000), created_at, updated_at. `(user_id, id)` 인덱스. 사용자 FK는 물리 삭제 시 cascade 한다.
- 실제 회원탈퇴는 users 골격을 남기므로 FK에 의존하지 않는다. MemberWithdrawalService에서 건의 본문을 같은 트랜잭션으로 즉시 삭제한다. 접수도 사용자 행 잠금과 탈퇴 여부 확인으로 직렬화해 탈퇴 직후 재생성을 막는다.
- `app_updates`: id, title(100), content(5000), created_at, updated_at. 관리자 삭제 시 즉시 파기한다.
- 건의 본문을 분석 이벤트·진단 로그에 넣지 않는다. 건의 수집과 이용 목적을 한국어/영어 개인정보처리방침에 명시한다.

## 배포 순서

추가 테이블 migration과 서버/API, 개인정보처리방침을 먼저 반영한 뒤 앱을 배포한다. 기존 컬럼·API는 변경하지 않는다. 앱에는 기존 로그인·온보딩·사진 채팅과 별개 메뉴로 추가하며 네이티브 설정이나 패키지를 변경하지 않는다.
