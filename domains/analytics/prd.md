# 제품 지표 PRD

루게더의 핵심 가설인 “루틴 수행과 공동 참여가 지속 행동을 만드는가”를 재현 가능한 수치로 검증한다. 마지막 접속 시각 한 점이나 화면 노출 수가 아니라, KST 일별 인증 활동과 실제 루틴 완료 행동을 분리해 관측한다.

## 검증할 질문

1. 가입한 사용자가 D1/D7/D30 exact-day에 다시 서비스를 사용하는가?
2. 사용자가 최근 7일 중 3일 이상 실제 루틴 완료 행동을 반복하는가?
3. 실제 사람과 집을 공유하는 사용자가 개인 사용자보다 완료율·스트릭·재시작률이 높은가?

제품 지표는 운영 판단을 위한 관리자 전용 정보다. 사용자 원문 루틴 제목이나 개인정보는 노출하지 않고 건수·비율만 제공한다.
