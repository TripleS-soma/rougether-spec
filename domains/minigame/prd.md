# 미니게임 PRD

## 목적

메인 방에서 루게더 고양이와 짧게 즐기는 게임을 제공한다. 게임별 개인 최고 기록으로 전체 회원과 순위를 비교할 수 있다.

## 사용자 경험

- 메인 `방` 오른쪽의 리퀴드 게임 아이콘으로 게임 목록을 연다.
- `루틴 러너`, `고양이 계단`, `고양이 합치기` 중 게임을 선택해 바로 시작하거나 해당 게임의 랭킹을 본다.
- 기존 루게더 고양이의 생김새와 앱의 리퀴드 디자인을 유지한다. 목록과 랭킹에는 조작에 필요하지 않은 소개·랭킹 원리 설명을 반복하지 않는다.
- 게임이 끝나면 이번 점수와 개인 최고점을 보여 준다. 기록 저장에 실패하면 같은 결과를 재전송할 수 있다.
- 새 앱은 난이도를 높인 규칙 2를 사용하며 기존 최고 기록과 전체 회원 랭킹을 그대로 이어서 사용한다.

## 범위

현재 3종 게임은 무료이며 입장 비용, 재화·아이템·경품 보상, 시즌 초기화를 제공하지 않는다. 방·집 레벨이나 루틴 완료 조건에 영향을 주지 않는다.

서버는 로그인한 회원에게 플레이 세션과 난수 시드를 발급하고, 게임 입력을 재생해 점수를 검증한다. 클라이언트가 계산한 점수를 그대로 받지 않는다. 검증은 규칙에 어긋난 기록을 차단하며, 규칙을 지키는 자동 플레이와 사람의 플레이를 구별하는 수단은 아니다.
