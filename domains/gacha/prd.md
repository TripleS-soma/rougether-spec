# 뽑기 도메인 PRD

상위 문서: [product.md](../../product.md) · [erd.md](../../erd.md) · [features.md](../../features.md) · [api.md](../../api.md)

## 목적

뽑기는 꾸미기 아이템과 캐릭터의 주요 획득 경로다(캐릭터 기본 1개는 온보딩에서 무료 선택). 루틴 실천으로 모은 **코인의 주요 소모처**이자, 랜덤 보상으로 방을 꾸미는 경험을 제공한다. 상점 전용 아이템을 모두 뽑기에 편입하는 변경은 아니다.

상점(다이아 직접 구매)과 달리, 뽑기는 코인을 써서 무엇이 나올지 모르는 랜덤 보상을 여는 경험을 제공한다. "오늘도 루틴을 했다"는 성취를 눈에 보이는 아이템 획득으로 환산해 핵심 경험 루프(루틴 완료 → 코인 보상 → 방·캐릭터 성장 시각화)를 닫는다.

## 사용자 가치

- **보상 환산**: 루틴으로 쌓은 코인을 캐릭터·방 꾸미기 아이템으로 바꾼다. 누적 보상이 시각적 결과로 남는다.
- **수집·기대감**: 벽지·바닥·가구 중 필요한 종류를 고르고, 여러 테마의 아이템을 한 상자에서 만난다. 새 테마가 추가되어도 꾸미기 뽑기 상자의 수는 늘어나지 않는다.
- **명확한 선택**: 신규 앱의 꾸미기 뽑기 화면은 **벽지·바닥·가구 3개 상자**만 운영한다. 테마는 보상 아이템의 속성으로 유지한다.
- **일관된 보상 연출**: 같은 등급의 모든 아이템에 공통 연출을 적용한다. 높은 등급은 더 특별하게 드러내되, 아이템마다 별도 영상을 제작하지 않는다.

## 핵심 시나리오

1. **상자 선택** — 벽지·바닥·가구 순으로 배치된 상자 중 하나를 선택한다. 처음에는 가구 상자를 선택하며, 실제 서버 머신의 비용과 획득 가능한 보상을 확인한다.
2. **뽑기 실행** — 단챠(코인 25) 또는 5+1회(코인 125)를 선택한다. 보유 코인이 부족하면 실행할 수 없다. 서버가 결과를 확정한 뒤 등급별 연출을 재생한다.
3. **결과 확인** — 아이템의 투명 배경 이미지를 연출 위에 표시한다. **이미 보유한 아이템은 다이아 3으로 전환**되며, 새로 얻은 꾸미기 아이템은 방 꾸미기로 이어서 배치할 수 있다. 연출을 건너뛰어도 지급 결과는 변하지 않는다.

## 경계 / 의존성

- **재화 차감·지급**: 코인 소모와 다이아 적립은 `user_wallets`(currency_type) 도메인의 지갑 갱신에 의존한다. 차감·지급은 하나의 쓰기 트랜잭션으로 묶는다.
- **아이템 지급**: 획득 아이템은 `user_items`로 인벤토리에 추가된다. 아이템 정의·상점·인벤토리는 [상점/아이템 도메인](../shop/features.md)에 속한다 — 뽑기는 `items`를 보상으로 참조만 한다.
- **테마**: 신규 3종 머신은 `theme_id = NULL`이며 여러 테마의 아이템을 포함한다. 보상 아이템의 테마 연결과 활성 검사는 유지한다. 기존 테마 머신과 캐릭터·악세사리 전용 머신의 직접 조회·뽑기 계약도 이행 기간에는 유지한다.
- **중복 판정**: "이미 보유한 아이템"은 사용자의 `user_items` 보유 여부로 판정한다. 방 꾸미기 아이템과 캐릭터 악세사리 모두 중복이면 다이아 3으로 전환한다.

## 확정 사항 (PRD 근거)

- 꾸미기 뽑기는 테마 공통 **벽지·바닥·가구** 3종으로 통합한다. 배경·캐릭터 악세사리는 이 3종 풀에 포함하지 않는다. 카탈로그의 모든 아이템을 자동으로 추첨 대상으로 삼지 않고, 적격 보상 풀 등록을 기준으로 운영한다.
- 신규 앱은 `GET /api/v1/gacha?catalog=category`를 사용한다. `catalog`를 생략하는 기존 앱에는 신규 3종을 제외한 기존 목록을 유지한다. 기존 머신 ID·풀·보유 이력을 삭제하거나 비활성화하지 않는다.
- 캐릭터는 온보딩에서 **기본 1개 무료 선택** + 나머지는 기존 캐릭터 뽑기로 획득한다. 신규 꾸미기 화면의 3개 상자와는 별개이며 비용·환급 정책을 바꾸지 않는다.
- 재화 2종 분리: **코인**(뽑기 비용) / **다이아**(중복 전환·아이템 구매).

## 미정

- 향후 코인 외 뽑기 비용 통화 허용 여부(현재 꾸미기 3종은 코인 25로 확정).
- 특정 등급 풀 전체가 비었을 때의 확률 재정규화 여부(현재 전체 활성 풀 균등 fallback 유지).
- 구버전 앱 지원을 종료하고 기존 테마 머신을 비활성화할 시점.
