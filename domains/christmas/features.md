# 크리스마스 이벤트 기능 명세

## 이벤트 구성

이벤트 코드 `christmas_2026`, 기간 2026-11-09~12-25 KST다. 선택된 부드러운 크리스마스 에셋과 패널 없는 벽지, 안내 팝업 revision 2-2, 선물 봉투 출석판을 사용한다. 출석 화면 제목은 `크리스마스`만 쓰고 소제목을 붙이지 않는다. 실제 현재 방 화면 위에 합성하며 오래된 배경 화면을 고정하지 않는다.

- 출석은 누적 30회, 일반 30코인, 5회마다 그날 총 60코인, 합계 1,080코인이다. 특별 완료 보상은 NONE이며 트리 지급안은 폐기했다. 유니크 보상은 나중에 결정한다.
- 뽑기는 승인 크리스마스 10종(트리 포함) 그룹 50%와 기존 벽지/바닥/가구 적격 합집합 그룹 50%다. 그룹 안 등급은 70/25/5이고 빈 티어는 실패 처리한다. 25코인 단챠/125코인 5+1, 중복 다이아 3은 기존 정책을 따른다.
- 가구 배치 종류당 10%는 기존 루틴/투두 완료 보너스 계약이며 출석 코인에는 추가 적용하지 않는다.

## 접속 노출 순서

1. metadata와 해당 출석 상태 조회가 끝난 뒤 결정한다. 로딩 중 안내 팝업을 먼저 띄우지 않는다.
2. 이벤트가 active이고 누적 30회 미만/오늘 미출석이면 출석판을 먼저 연다. 출석 버튼을 눌러 ID 지정 출석 API를 호출하고 중복 입력을 잠근다.
3. 성공 시 실제 지급 코인을 연출하고 닫는다. 출석판 닫힘/보상 연출이 **완전히 끝난 뒤** 노출 가능한 이벤트 안내 팝업을 연다. 직접 닫았을 때도 닫힘 완료를 기다린다.
4. 오늘 이미 출석했거나 누적 30회 완료면 출석판을 건너뛰고 안내 팝업만 검토한다. 영구 숨김 상태/종료 후에는 안내 팝업을 생략한다.

단일 대기열로 동시에 하나의 화면만 연다. 닫힘 콜백/상태 조회 중복으로 같은 접속 흐름에 화면을 재등록하지 않는다. 출석 요청 중/실패 시 출석판을 유지하고 후순위 팝업을 대기시킨다. 기존 STREAK 자동 출석 시트와도 겹치지 않게 순서를 조정한다.

## 출석판과 당일 숨김

- 5열 6행의 1~30번 봉투는 날짜가 아닌 누적 순번이다. 미수령은 닫고 다음 받을 번호만 강조한다. 수령 여부와 N/30은 서버 `progressDays`/`dailyRewards`를 정본으로 삼는다.
- 출석 성공 후 같은 KST 날짜 자동 재노출은 서버 `checkedInToday`로 막는다. 기기 날짜나 버튼 터치만으로 성공 처리하지 않는다. 실패/응답 유실은 GET 및 지갑 재조회로 수렴한다.
- 다음 KST 날짜 첫 접속 시 재조회하고 미출석/미완주/기간 안일 때만 자동 표시한다. 자정에 다른 화면을 강제로 가리지 않는다. 당일 직접 열기는 허용하되 출석 버튼은 비활성이다.
- 누적 30회/종료 후 자동 표시를 중단한다. 이력은 직접 조회 가능하다. 11/26은 12/25까지 30회를 채울 수 있는 마지막 첫 참여일이며 이후 참여에는 남은 날짜를 안내한다.

## 안내 팝업 영구 숨김

`다시 보지 않기`는 **안내 팝업 왼쪽 아래에만** 두고 기본 미선택이다. 출석판에는 넣지 않는다. 선택 시 서버에 계정+안정적인 이벤트 코드로 영구 저장하여 문구/이미지 개정, 재설치, 재로그인에도 유지한다. 저장 실패는 성공으로 표시하지 않고 재시도한다.

영구 숨김은 안내 팝업의 자동 노출만 중단한다. 다음 날 출석판, 이벤트 메뉴 직접 진입과 팝업의 이벤트 뽑기 바로가기는 독립된 흐름이다. 사용자가 직접 누른 바로가기는 실제 metadata ID로 뽑기 탭을 연다. 출석 화면에서 확률 50%나 배치 보너스 문구를 큰 소제목으로 반복하지 않는다.

## 공개와 호환

기존 STREAK API와 루틴/투두 완료 후 자동 출석 동작을 보존한다. 크리스마스는 ID 지정 CUMULATIVE API로 분리한다. V100은 모드/누적 코인 진행/계정별 팝업 숨김, V101은 비활성 전용 머신과 승인 10개 풀을 준비한다. 공개 플래그는 기본 OFF이며 서버/새 iOS 빌드와 실제 운영 데이터를 검증한 후 승인된 운영 공개 절차에서 켠다. 문서/코드 존재만으로 오픈 완료라고 표현하지 않으며 가구 배치 보너스는 `CHRISTMAS_EVENT_ENABLED`와 `CHRISTMAS_COIN_BONUS_ENABLED`가 모두 ON이어야 적용된다. 공통 이벤트 플래그 OFF로 팝업/신규 출석/전용 뽑기/가구 보너스를 함께 중단하고 일일 원금 100코인 한도는 유지한다. 실제 사용자 알림은 발송하지 않는다.

데이터와 endpoint는 [api.md](api.md), [출석 API](../attendance/api.md), [뽑기 API](../gacha/api.md)를 따른다.
