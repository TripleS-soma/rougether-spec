# 고양이 앱 아이콘 PRD

## 목적

앱 방문과 루틴 실천에 맞춰 기존 집·고양이 아이콘의 표정을 바꾼다. 꾸준히 실천하면 함께 기뻐하고, 오래 방문하지 않으면 기다리는 고양이를 보여 준다. 미접속 알림도 같은 고양이 말투를 쓴다.

## 사용자 경험

- 기본·기다림·눈물·울음·오늘 성공·왕관의 6가지 상태를 제공한다.
- 완료한 날에는 기쁜 표정, 유효 루틴 스트릭이 7일 이상이면 왕관을 보여 준다.
- 2·4·7일 미접속 시 기다리는 정도를 높인다. 복귀하면 미접속 상태를 즉시 해제한다.
- 복귀 알림은 단계마다 한 번만 보내고, 긴 공백 뒤 여러 알림을 몰아서 보내지 않는다. 문구는 짧고 다정한 고양이 말투로 쓴다.

## 범위

서버는 상태·문구와 실제 foreground 활동 기록, 기존 FCM을 통한 미접속 알림을 제공한다. 이미지 번들 등록과 OS 아이콘 교체는 모바일 책임이다. 앱이 실행되지 않는 동안 특정 시각에 OS 아이콘이 자동으로 바뀐다고 보장하지 않는다.

기존 루틴·투두 완료, 스트릭, 보상 계약을 그대로 읽어 판단한다. 새 보상이나 다른 담당 도메인의 완료 규칙을 추가하지 않는다.
